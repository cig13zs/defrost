Defrost privacy policy

Defrost does not collect, store, sell, or transmit personal data.

The extension runs only after you click its toolbar button. Chrome grants temporary access to the active tab so Defrost can restore text selection, copying, right-click, and scrolling. That access ends when the tab or page changes.

Defrost has no analytics, account system, remote server, advertising code, or persistent host access. The Ko-fi and GitHub links open those sites only after you click them.

Chrome Web Store Limited Use

Defrost's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Temporary page access is used only for the visible restoration requested by the user. Page data is not collected, transferred, used for advertising or credit decisions, or used for an unrelated purpose.

Questions can be filed in the public GitHub repository.
